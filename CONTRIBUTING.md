# Katkıda bulunma

Teşekkürler! 🌿 Firefox-ı Âlâ'yı geliştirirken **ShyFox'un görünümünü korumak** temel öncelik.

1. Bir hata raporu/özellik isteği aç ve Firefox sürümü + işletim sistemi + beklenti/gerçekleşen davranışı belirt.
2. CSS seçici değişiklikleri için mümkünse ilgili Firefox sürüm notu veya upstream ShyFox PR'ına bağlantı ver.
3. Var olan görünüme dokunan değişikliklerde **önce/sonra** ekran görüntüsü paylaş. Şifre, çerez ve kişisel sekme bilgilerini gizle.
4. `python3 -m unittest discover -s tests -v` çalıştır.
5. PR başlığında hangi sorunun düzeltildiğini açıkça belirt ve otomatik testle doğrulanmamış davranışları bildiğin kadarıyla yaz.
