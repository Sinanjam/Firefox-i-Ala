# Güvenlik ilkesi

Bu depo Firefox kullanıcı arayüzü için özelleştirilmiş CSS ve yerel kurulum araçları içerir. Tarayıcı güvenlik güncellemesi yerine geçmez.

- Firefox'u güncel tut.
- Profilini (`prefs.js`, çerezler, şifreler, oturum dosyaları) bug raporuna ekleme.
- Kurulum araçlarını kullanmadan önce yedek al; betikler açık Firefox üzerinde çalışmayı reddeder.
- Güvenlik açığı olduğundan şüpheleniyorsan hassas ayrıntıları herkese açık issue yerine depo sahibine GitHub üzerinden özel olarak ilet; mümkünse "Report a vulnerability" özelliğini kullan.

Güvenlik desteği: `0.1.x` deneyseldir; resmi destek SLA veya garanti bulunmaz.
